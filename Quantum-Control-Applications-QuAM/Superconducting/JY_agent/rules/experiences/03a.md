## Lesson — 2026-09-04/05 operator: ~200 MHz fine window; lower amp for broad or multi-peak

- Device/project: `as-qpu-10qV2_agent`
- Observation: operator said 03a does not need a 40–50 MHz remaining window;
  about 200 MHz is fine enough once a candidate is centered. Power-broad FWHM
  and multi-peak clutter (for example multiplexed fine traces that look like
  several local peaks in one panel) should be fixed by lowering
  `operation_amplitude_factor`, not by endlessly narrowing the span.
- Recovery: keep refinement/final span near ~200 MHz. If FWHM is still above
  the allowed interval, or if many peaks remain visible, reduce amplitude
  further (for example from 0.05 toward 0.03–0.02, historically even 0.002 on
  this device) and remeasure at the same centered window.
- Do not copy a specific amplitude as universal; each qubit must still pass
  fit, SNR, edge, and FWHM checks independently.
