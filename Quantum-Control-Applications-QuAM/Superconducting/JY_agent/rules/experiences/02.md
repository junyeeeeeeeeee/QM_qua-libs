# 02 Broadband resonator survey experience

## Lesson — 2026-10-04 22:55 Asia/Taipei

- Device/project: `as-qpu-10qV2_agent` (node run outside JY on a scratch copy
  of the state; no workflow, no state commit)
- Node: `02`; both readout lines (con1-7-1: q1–q5, con1-8-1: q6–q10)
- Parameters: node defaults (`num_averages=100`, `max_if_in_mhz=400`,
  `frequency_step_in_mhz=0.1`, `readout_length_in_ns=2000`, 02x probe power)
- Electrical delay: 387 ns (7-1) and 396 ns (8-1). With 0.1 MHz steps the
  phase advances about 0.25 rad per point, so the median phase step recovers it.
- Found: five deep resonances per line (−14 to −25 dB), within 1 MHz of the
  stored bare frequencies: 7-1 5.9453/5.9957/6.0490/6.0965/6.1700 GHz,
  8-1 5.9463/5.9964/6.0501/6.0989/6.1713 GHz.
- Artifacts to expect on this hardware: a strong LO-leakage feature about
  ±8 MHz around each LO (hence `lo_guard_in_mhz=10`), and on 7-1 two
  single-sample spurs at IF ≈ ∓353 MHz (5.670 and 6.376 GHz), rejected by
  `min_linewidth_in_mhz=0.3`. Weak (≥ −2 dB) features at 6.24–6.31 GHz are
  listed as candidates but never selected over the resonators.
- Design matching check: a design list equal to the stored frequencies +12 MHz
  with q2 offset a further +25 MHz gave a global shift of −12.63 MHz and flagged
  only q2 (−24.5 MHz) as `mismatch`; the other nine matched within 1.5 MHz.
- Applicability: a survey, not a calibration. 02x still fine-tunes every
  resonator afterwards.
