## Lesson — 2026-09-04 operator: multiplex-first T1

- Device/project: `as-qpu-10qV2_agent`
- Observation: historical isolated q3/q4/q5 T1 references are valid evidence,
  but they are not the starting strategy. Operator asked to measure all active
  qubits together first, like 02x.
- Recovery: first 05 must multiplex every active target with the same wait
  window. Isolated T1 is a last-resort retry after a shared-parameter
  multiplex retry, or when wait ranges cannot be shared.
- Do not copy this as an accepted setting.
